# AI_Project

Pathfinder AI is an interactive web-based application designed to simulate intelligent route navigation from a warehouse (or any location) to multiple destinations using advanced pathfinding algorithms.

The system visually demonstrates how algorithms like A*, Dijkstra, and Greedy Best-First Search compute optimal paths on a network graph with real-time animation and modern UI.
Key Features
 Interactive network graph visualization
 Multiple AI-based algorithms:
A* Algorithm
Dijkstra Algorithm
Greedy Best-First Search
 Dynamic start location selection
 Multi-destination routing support
 Displays:
Total distance
Nodes visited
Complete path
 Smooth animated path traversal
 Zoom, pan, and hover tooltips
 Futuristic and responsive UI design
 Select a starting location (default: Warehouse)
Choose one or more destination points
Select an algorithm (A*, Dijkstra, Greedy)
Click "Compute Route"
The system:
Computes the optimal path
Animates the route on the map
Displays distance and traversal details
