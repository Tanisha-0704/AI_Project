# AI_Project

## Pathfinder AI

Pathfinder AI is a web-based application that helps in understanding how intelligent route navigation works. It simulates finding the best path from a warehouse or any starting point to one or more destinations using well-known pathfinding algorithms.

The application visually shows how algorithms such as A*, Dijkstra, and Greedy Best-First Search calculate the most efficient route on a network graph. It also provides real-time animation to make the process easy to understand.

## Key Features

Interactive network graph visualization

Support for multiple algorithms including A*, Dijkstra, and Greedy Best-First Search

Option to choose different starting locations

Ability to select multiple destinations

Displays useful information such as total distance, number of nodes visited, and the complete path

Smooth animation of the selected route

Zooming, panning, and hover details for better interaction

Clean and responsive user interface

## How It Works

First, the user selects a starting location, which is set to warehouse by default.

Then, one or more destination points can be selected.

After that, the user chooses an algorithm such as A*, Dijkstra, or Greedy Best-First Search.

Finally, by clicking on "Compute Route", the system processes the request.

## System Functionality

Once the route is computed, the system finds the optimal path based on the selected algorithm.

It then animates the path on the graph and shows details like total distance, nodes visited, and the final path taken.

## Technologies Used

JavaScript or React for frontend development

Graph algorithms for implementing AI logic

HTML and CSS for designing the user interface

## Objective

The main objective of this project is to demonstrate how different pathfinding algorithms work in a simple and interactive way so that users can easily understand their behavior.
